### 🎬 MCU Intelligence Dashboard & Success Prediction System

> **Complete data analytics lifecycle project on 49 Marvel Cinematic Universe titles (2008–2025)**

| Phase | Tools Used | Deliverable |
|-------|-----------|-------------|
| 🧹 Data Cleaning | Python, Pandas, NumPy | Clean dataset (49 MCU titles) |
| 📊 EDA | Matplotlib, Seaborn | 10+ Marvel-themed visualizations |
| 🗄️ SQL Analysis | MySQL | 5 normalized tables · 6 views |

- 🎯 3 K-Means Clusters: MCU Legends · Successful Heroes · Struggling Titles
